# 요구사항 및 완료 기준

## 목표와 범위

한국의 관광지·음식·숙박·행사 등을 지역과 유형으로 탐색하고, 회원이 여행 계획과 Hot Place를 기록·공유하는 Servlet/JSP 웹 서비스를 만든다. 명세서 1.4절의 **필수, 추가(선택), 심화(선택), 기타** 기능을 이번 구현 범위에 모두 포함한다. 이전 프로젝트의 화면이나 코드는 저장소에 없으므로 모든 화면을 새로 작성한다.

명세서의 요구사항 표는 일부 행과 번호가 어긋나 있으므로, 아래 번호는 각 기능의 상세 설명(8~16쪽)을 기준으로 정리했다. F111~F114는 표의 기능명을 기준으로 정리했다.

## 기능 요구사항

| 번호 | 기능 | 구현 완료 조건 |
| --- | --- | --- |
| F101 | 지역별 관광지 | 한국관광공사 데이터를 수집하고 지역별 전체 목록·상세를 조회한다. |
| F102 | 관광지·숙박·음식점 | 지역과 유형을 조합해 검색하고, 결과가 없을 때 빈 상태를 표시한다. |
| F103 | 문화시설·공연·여행코스·쇼핑 | F102와 동일한 검색 방식으로 네 유형을 조회한다. |
| F104 | 여행 계획·경로 | 로그인 회원이 일정, 관광지 방문 순서, 예상 경비, 상세 메모를 저장·수정·삭제한다. 목록의 드래그앤드롭 순서가 DB에 반영되고 공개한 계획은 공유 URL로 조회된다. |
| F105 | Hot Place | 로그인 회원이 장소·방문일·유형·설명·사진·지도 위치를 등록하고 본인 항목을 수정·삭제한다. 목록·상세·지도에서 조회된다. |
| F106 | 관광 뉴스 | 공개 RSS에서 관광 관련 기사의 제목·발행일·출처·원문 URL을 중복 없이 수집해 목록으로 제공한다. |
| F107 | 회원 관리 | 회원 가입, 내 정보 조회·수정, 탈퇴가 가능하다. 중복 계정과 잘못된 입력은 거부한다. |
| F108 | 인증·비밀번호 찾기 | 로그인·로그아웃, 사용자 초기화 요청, 관리자 본인 확인 후 임시 비밀번호 발급, 임시 비밀번호 변경을 제공한다. |
| F109 | 공지사항 | 누구나 조회하고, 관리자만 등록·수정·삭제한다. |
| F110 | 공유게시판 | 누구나 조회하고, 로그인 회원만 등록하며 작성자만 수정·삭제한다. |
| F111 | 날씨 | 관광지 좌표의 현재 날씨와 5일·3시간 간격 예보를 표시한다. |
| F112 | 관광지 사진 | API에서 제공하는 사진을 관광지별로 표시하고 사진이 없을 때 대체 화면을 사용한다. |
| F113 | 일출·일몰 | 관광지의 선택 날짜와 좌표에 맞는 일출·일몰 시각을 표시한다. |
| F114 | 전기차 충전소 | 관광지 주변 충전소의 위치와 확인 가능한 최신 충전 상태를 지도·목록에 표시한다. |

여행계획 공유는 명세서 1.4절 서술 요구사항도 반영한다. 공개 여부를 계획별로 지정하고, 비공개 계획은 소유자만 조회한다. 공지·게시판·Hot Place 목록과 상세는 로그인 없이 조회 가능하다.

## 비기능 요구사항

| 번호 | 기준 | 적용 방식 |
| --- | --- | --- |
| NF101 | 사용 편의성 | 한국어 메뉴, 명확한 입력 오류와 빈 결과 안내, 공통 탐색 구조를 제공한다. |
| NF102 | 기기 접근성 | 휴대전화와 데스크톱 너비에서 목록·상세·폼·지도를 사용할 수 있도록 반응형 화면을 만든다. |
| NF103 | 조회 응답성 | 관광지 조회는 적재된 DB와 지역·유형 인덱스를 사용하고 페이지 단위로 결과를 보여준다. 실시간 부가 정보는 별도로 요청한다. |
| NF104 | 데이터 정확성 | 공공데이터의 원본 ID·출처·갱신 시각을 저장하고, 날씨·충전 상태에는 조회 시각을 표시한다. |

## 운영·보안 규칙

- 비밀번호는 복구 가능한 평문으로 저장하지 않고 강한 해시로 저장한다. 로그인 시 세션을 재발급하고 로그아웃·탈퇴 시 무효화한다.
- 변경 요청은 서버에서 로그인·역할·소유권을 검사하고 CSRF 방어 및 입력값 검증을 적용한다. 출력은 JSP에서 이스케이프하며 SQL은 PreparedStatement로 실행한다.
- 관리자 계정은 초기 설치 절차에서 만든다. 사용자 비밀번호 초기화 요청은 관리자 화면에 표시하고, 관리자가 별도 채널로 본인 확인 후 임시 비밀번호를 발급한다. 임시 비밀번호는 한 번만 표시하고 다음 로그인에서 변경하게 한다.
- 사용자 탈퇴 시 해당 계정의 여행 계획·Hot Place·공유게시판 글·초기화 요청을 삭제하고 세션을 종료한다. 공지 작성에 사용된 관리자 계정은 탈퇴 대상에서 제외한다.
- 뉴스는 원문을 복제하지 않고 원문 링크를 제공한다. 외부 사진과 뉴스에는 출처를 표시한다.
