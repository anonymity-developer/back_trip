# DB 단계 실제 실행 화면

2026-11-06(KST), Chrome에서 `http://127.0.0.1:18080/enjoytrip`의 실제 앱 화면을 캡처했다. 앱은 관광지 50,915건의 `enjoytrip_test`에 연결했다. 이미지는 합성·내용 편집 없이 브라우저 출력 그대로 저장했다.

일부 원본 사진은 없거나 외부 URL 로딩에 실패해 기존 대체 카드가 표시된다. 상세 스크린샷 한 장으로 아래쪽 실시간 정보의 실제 API 성공을 증명하지 않는다. 관리자 화면에는 실제 서비스 비밀번호·키를 표시하지 않았다.

회원·비공개·권한·업로드·비밀번호 초기화 검증은 이미지 개수로 판단하지 않고 [HTTP 검증 결과](../verification.md)를 함께 확인한다. [직접 테스트 안내](../../../docs/db/06-local-test.md)를 따라 같은 DB·화면을 재현할 수 있다.
