## 검색 측정

관광지 50,915건의 로컬 HTTP 응답을 각 5회 측정했다. JSP·DB 처리와 응답 본문 수신을 포함하며 브라우저 이미지·지도 타일 로딩은 포함하지 않는다. 동시 부하·운영 SLA·외부 API 지연을 검증한 수치가 아니다.

| 경로 | 표본 5회(ms) | 중앙값(ms) |
| --- | --- | --- |
| `/attractions` | 99.86, 86.23, 87.37, 97.62, 100.42 | 97.62 |
| `/attractions?region=1&type=39` | 45.15, 36.48, 40.30, 45.00, 44.32 | 44.32 |
| `/attractions?page=100` | 195.11, 178.29, 178.35, 171.29, 198.21 | 178.35 |

지역·유형 조건의 실제 EXPLAIN에서 `type=ref`, `key=idx_attractions_filter`, 예상 행 2,326을 확인했다. 이 결과만으로 모든 LIKE·전체 목록·후반 페이지가 같은 인덱스를 쓴다고 일반화하지 않는다. 근거 없이 인덱스를 추가하지 않았다.

## 남은 확인과 재현 방법

- 실제 관광지·사진·RSS·날씨·일출·충전소 외부 호출은 키·승인·접속 환경을 준비한 뒤 확인해야 한다. 이번 HTTP 검증은 키 없는 날씨 503과 저장된 주요 화면 유지까지다.
- MySQL 8.4에서의 실행은 미실시다. 제공 비고유 FK는 복합키로 개선했지만 실행 검증 결과를 8.4 통과로 확대하지 않는다.
- 기존 실제 DB의 환경·코드·파일 상태에 맞춘 백업·업그레이드·전환은 아직 적용하지 않았다. 검증 DB의 데이터를 실제 사용자 데이터로 주장하지 않는다.
- 실제 사진 파일이 있는 운영 환경의 복구는 미실시다. 검증용 DB 백업·테이블·계획/관광지 참조 복원을 확인한 범위와 구분한다.
- GitLab 제출·업로드는 수행하지 않았다. 제출 경로·형식은 담당자의 반별 규칙을 따른다.
